# @ollo/ui

Shared design tokens for OllO clients.

| Token | Dark | Light |
|---|---|---|
| bg | `#070A0E` | `#F3F5F8` |
| elev | `#141B24` | `#FFFFFF` |
| accent | `#3EE0B2` | `#1AA883` |
| text | `#EEF3F8` | `#121820` |
| danger | `#FF6B7A` | `#C43D4C` |

Type: Manrope (UI), IBM Plex Mono (safety numbers).

Native apps re-implement these tokens (Compose Color / SwiftUI Color).
The web client lives in `apps/web/src/styles.css`.
